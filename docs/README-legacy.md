# 生肖观察

中文生肖统计实验工具。数据自动取自用户指定的2025年及当前年份历史接口，保留同一期重复生肖、按期号去重。保留原有算法，并提供短期多窗口、自适应组合切换；每种算法对应自己的候选、排序、回测和明细，浏览器记住上次选择。

网站运行在Sites托管环境。后端模型由Python原公式移植，12个估计概率和当前实验模型的验证、回测指标已与Python参考核对。理论相同的概率在1e-12精度内按生肖顺序打破平局，避免浮点误差决定候选。

## 三种算法（2026-10-15-v2）

- 原算法：保留90期半衰期、60期先验强度及原2025选模结果，默认仍显示该算法。
- 短期多窗口：以生肖出现与其当期理论概率的差值为统计对象；7、14、30期窗口分别使用12、20、30的先验强度，按25%、35%、40%混合。
- 自适应组合：六个专家为7期、14期、30期、多窗口、30期转移、90期转移。以每个专家此前最多60期的平均命中计算softmax权重，温度0.15，并混入10%均匀权重。前90期热身，先预测、再观察结果、最后更新权重，不使用本期开奖结果生成本期预测。

所有模型保留4号码与5号码生肖的理论差异，没有固定排除或强制轮换任何生肖。换组率衡量集合变化，不能解释为准确率。

## 回测范围与证据

回测指标和明细均覆盖2026年起的全部记录；截至2026-10-15为288期，从01-01至10-15。旧版只向页面返回最后60条，导致明细止于08-17；本版返回全部明细，页面可分批展开或显示全部。

2026年历史此前已经用于旧模型评估。因此新算法比较属于重复使用历史的探索，不能称为新的独立测试。目前三种方法均没有显示出相对于号码数量匹配随机基准的稳定优势。模型规则已固定，需以后续新开奖检验。Python探索结果保留在research/comparison.json，包含未上线方法及其较差结果；网站采用原有JS平局规则，research/published-comparison.json是上线版本的准确指标。

恢复旧持久化文件时，使用保存的原始记录按当前算法重新计算，避免旧的分析缓存遮盖本次更新。

## 访问

- 平台当前支持公开网址，页面及模型数据仍受固定密码保护。
- 页面额外使用用户指定的固定密码，通过后端校验。
- 运行密钥ACCESS_PASSWORD、SESSION_SECRET与UPDATE_TOKEN由Sites保存，不写入源码或客户端。
- 登录使用签名、8小时有效的HttpOnly/Secure/SameSite Cookie。

## 数据更新

页面打开时获取记录，页面可见时每5分钟刷新。API失败会清楚显示历史快照及其真实日期。

数据写入BUCKET的zodiac/state-v1.json，页面关闭后仍保留。关联自动任务在北京时间每日21:35调用共享更新入口，执行和核验步骤见AUTOMATION.md。此接口额外校验从Sites读取的站点服务凭据，只允许有授权的自动任务写入。

## 核验

TypeScript类型检查、托管构建、Python模型对照、重复记录、重复生肖、前向回测隔离、签名过期和跨站来源校验。

运行 `node --experimental-strip-types scripts/verify-models.mjs` 可重现三种模型的指标，并检查全部288条明细与汇总一致、7个历史截点（包含农历跨年）的前向隔离、原算法不变和自适应权重归一。

未启用浏览器自动化环境，因此未进行浏览器画面验收。
